# M4.2 Trip Plan / Timeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a DB-first collaborative Trip Plan timeline derived from existing Trip dates, with optional Board/Poll references and server-authorized Realtime refetch.

**Architecture:** Store Plan items with `trip_id` and `day_date`; derive all Day sections from the Trip date range. Thin Route Handlers call server-authorized RPCs, while a server-composed read model returns items and reference summaries in one response. Extend the existing SSE bridge with a Trip-scoped `plan` scope and refetch authoritative state after events.

**Tech Stack:** Next.js 16 App Router, TypeScript, React 19, Supabase PostgreSQL/RPC/Realtime, Vitest, Playwright.
